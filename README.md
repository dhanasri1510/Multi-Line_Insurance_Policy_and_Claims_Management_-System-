# Multi-Line Insurance Policy and Claims Management System

A Salesforce CRM-based solution to manage Vehicle, Property, and Life insurance policies and claims on a single platform.

## Problem
Manual and inconsistent policy quoting, premium calculation, and claims handling.

## Solution
- Screen Flows for automated policy quoting
- Record Types and Field Sets for multiple insurance products
- Apex for premium calculation
- Record-Triggered Flow for automatic claim routing
- Approval Process for high-value claims
- Lightning Web Component (LWC) for the Claims Dashboard
- Validation Rules for data accuracy
- Permission Sets and Sharing Rules for secure access
